ontario-fir-formatter

A zero-dependency TypeScript utility for parsing and decoding Ontario Financial Information Return (FIR) Schedule, Line, and Column (SLC) codes.

Installation

Clone the repository and integrate the TypeScript module directly into your ETL pipeline or data engineering stack.

Usage Example

import { parseSLC, decodeCategory } from './ontario-fir-formatter';

// Parse a raw string from the Ontario Open Data FIR CSVs
const parsed = parseSLC("40 1199 01");
const category = decodeCategory(parsed.schedule, parsed.line);

console.log(category.lineDescription); 
// Output: "Total Police Services"
